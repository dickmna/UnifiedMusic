# Optional Original Audio — HQ 1.0.0

Install `Harmonia-Original-Audio-HQ-1.0.0.zip` through the same mod manager as the main DLL. It adds `SKSE/Plugins/HarmoniaOriginalAudio.json` and loose `Music/Harmonia/Original/*.xwm` files. No ESP, BSA registration, generator or additional framework is required. The DLL alone does not add original audio alongside a replacer.

The pack contains 239 verified audio files (48 kHz, 192 kbit/s XWMA), 231 distinct main/finale pairs corresponding to 247 original track records, including 19 records with finales. The DLL still limits automatic use to eligible ordinary playlists. Including an asset is not permission to distribute it to a story or Boss playlist.

The source is **Music Replacer Reverter v1 by MadAborModding**, [Nexus 137806](https://www.nexusmods.com/skyrimspecialedition/mods/137806), file 578246. Its author identifies **Unofficial High Definition Audio Project by sharrken**, [Nexus 18115](https://www.nexusmods.com/skyrimspecialedition/mods/18115), as the audio source. Credit also belongs to Bethesda and the original music creators, including Jeremy Soule. Harmonia supplies the independent paths and verified manifest; it does not claim authorship of the music.

Permissions checked on 2026-11-15: MRR permits asset reuse and modification, and uploads to other sites with creator credit. It prohibits selling files containing its assets and permits Donation Points. UHDAP declares [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) and permits reuse/editing. These are the respective mod authors' published permissions; they do not transfer third-party rights or make Harmonia the owner of the compositions. This optional resource archive is separate from the AGPL code license and is not offered for sale.

Source archive: `Music Replacer Reverter - Main File-137806-1-1735710215.7z`, 447,902,545 bytes; SHA-256 `7a4209dd4d9a4d58f832f8cafffd1a4b3fd1e39d45f8ea3ad9a810c1812c6420`.

Packaging uses the previously downloaded archive. Each copied MUST was matched to its original record by EditorID, then its main/finale paths were checked against the original paths after removing the source's `_revert` suffix. Native cue points matched exactly, every resource is structurally valid XWMA, and all paired HQ/stock durations differ by at most 0.25 seconds. All 239 packaged files also passed full FFmpeg decoding with no errors; this does not execute Skyrim playback. Only the source mod's audio is copied into this archive, byte-for-byte under new independent names. MRR's ESP/INI, vanilla archive bytes, Lorkhan, paid Creation and regional-mod resources are not included. Archive unpacking is a development packaging step; neither the shipped DLL nor inspector contains a BSA reader.

Four MRR records (`MUSDread01`, `MUSDread03`, `MUSDread04`, `MUSDread01a`) copy legacy Skyrim records with unresolved audio paths and are excluded. They are not broken references inside this pack. Unreferenced source files are omitted. The five Update.esm Creation Club Oblivion dungeon cues also have no verified resource in this source. They retain their currently installed audio; this pack cannot add their hidden originals. Harmonia does not redirect missing references authored by other mods.

The 1.0.0 reference audit rechecked all 247 source records against the unchanged original plugin evidence, including complete main/finale paths and cue-point arrays. All 231 registered pairs and 239 independent files agree, with zero missing or orphaned pack assets. No BSA was opened for this recheck. The packager now requires the audited manifest fingerprint before writing an archive: `manifest_sha256` hashes UTF-8 text with LF line endings, so LF/CRLF checkouts agree. A changed main/finale relationship requires a new source audit even if every individual audio file still passes its own hash check.

The manifest records original resource paths, independently named HQ files, SHA-256 fingerprints for known stock/HQ encodings and verified main/finale relationships. Hashes identify known bytes, not arbitrary musical similarity. Missing/corrupt/mismatched optional files skip that pair; other compatibility work continues. Same-playlist existing stock/HQ copies, including the verified MRR copies, suppress an additional Harmonia use. Existing memberships, weights and authored conditions are retained; a copy with narrower conditions is not silently broadened. Unknown re-encodings and palette-contained copies are not promised perceptual deduplication.

Reproduction for developers: unpack the identified MRR archive/BSA into a private directory, then run `python tools/package_original_audio.py --source EXTRACTED_DATA_ROOT --output Harmonia-Original-Audio-HQ-1.0.0.zip`. The tool reads only the verified source paths from `tests/audio-pack-results.json`, checks their SHA-256 against the manifest, renames them in the ZIP and verifies every packaged byte. It contains no BSA reader and does not access game Data. Players install the finished ZIP; they do not run this tool or extract game archives. The stock fingerprints were established once from the supported locally owned game version. Do not put music files in the Git repository.
