# Provenance

Harmonia was named UnifiedMusic through version 0.4; the technical repository and DLL names remain UnifiedMusic. The repository is AGPL-3.0-or-later. Attribution and retained license copies do not relicense third-party contributions.

- **Music Type Distributor**: ThirdEyeSqueegee; `stop-sine/MusicTypeDistributor-RE`, commit `9a4cdf112c64bff91bec8f834c62bd00c46d2fe1`. Original GPL-3.0-or-later, exceptions and manifest are retained in `vendor/MTD`. Version 0.6 introduced a small additive existing-type INI adapter using that source as its syntax/behavior reference; 0.9 retains it. The type factory, Location/Region engine, clears and SimpleIni are not compiled.
- **Combat Music Extender**: `SeaSparrowOG/CombatMusic`, commit `302c6df30348ce83cfcf72cbf6ae4e8681fcc7b6`. The source's AGPL-3.0 license and manifest are retained in `vendor/CME`; conflicting website metadata is not used as a relicensing basis. Version 0.7 adapts its six default-music call sites, six filters and matching priority in `CombatSelector.cpp`, `SelectorPlan.cpp` and `SelectorRules.h`. The runtime adds strict reference validation, preflight checks, ambiguous/unavailable-choice fallback and separate combat/cleared bookkeeping. It omits ActorUpdate polling and the optional combat-music fix. This adaptation is compiled into the DLL.
- Versions 0.1/0.2 contained broader MTD/CME adaptations. Version 0.3 removed them. Those historical trees remain in their tags; 0.9 does not mechanically re-add the old modules.
- **Native interfaces**: CommonLibSSE at `2415cc998b611d3f0ac15fcfeadca9c83b1bf7f8` and commonlib-shared at `29fbdb0e2dc548c9ab22f6964981d75090dc9094`. Native single-instance creation uses the engine's stateless factory. Local read-only executable inspection identified the 1.7.104 condition-holder pointer discrepancy and interface dispatch. No executable bytes or disassembly are included.
- **JsonCpp**: `open-source-parsers/jsoncpp`, commit `89e2973c754a9c02a49974d839779b151e95afd6`, statically linked for JSON parsing. Its license is included in the binary archive, along with CommonLibSSE/commonlib-shared, spdlog and zlib notices. All dependency pins are in `cmake/Dependencies.cmake`.
- **Music Replacer Reverter v1**: MadAborModding, Nexus 137806, file 578246. Downloaded previously for local verification; archive SHA-256 `7a4209dd4d9a4d58f832f8cafffd1a4b3fd1e39d45f8ea3ad9a810c1812c6420`. Only its ESP and INI were extracted for record/config analysis. Aggregate findings are published; no original files or music are included.
- Record layouts were checked against TES5Edit's `Core/wbDefinitionsTES5.pas`. BSA access is a small bounded original-audio reader, not a general archive extractor. Offline real-audio tests used locally owned game resources in a private workspace; packages contain only code, docs, checks and licenses.

Version 0.8 unified condition decoding, typed VMAD reference reading, playlist-local scene guards and audio preparation. Version 0.9 replaces scene-expression negation with inheritance of the author's added ordinary-track clauses, retains read-only scene expressions, and limits failure fallback to dependent uses. Actual Orsinium main/finale resources were read into a private test overlay for validation; neither resources nor raw proprietary records are distributed. The six CME-derived selector entry points remain attributed above; no additional upstream framework was merged.

No game data, paid Creation plugin, Papyrus script, downloaded music pack, audio cache or BSA is redistributed.
